# Product Context: CoAuth

## 1. Problem Solved

Creative writing, especially for long-form narratives like novels or screenplays, is a cognitively demanding task. Authors must juggle plot threads, character arcs, world-building details, and consistent stylistic tone. Keeping all of this information mentally accessible is a major challenge that can lead to inconsistencies, writer's block, and a fragmented drafting process.

Existing writing tools are often passive text editors or complex project management suites that don't actively participate in the creative process. They store information but don't synthesize it.

## 2. Product Goals

CoAuth aims to be an active partner in the writing process. It addresses the core problem by:

*   **Externalizing Cognitive Load:** The "World Bible" and "Style Guide" act as an external, queryable memory for the project's canon, freeing the author to focus on creativity rather than rote memorization.
*   **Enhancing Creative Flow:** By handling tedious tasks like consistency checks ("Have I described this character's eye color differently before?") and initial drafting, CoAuth allows the author to maintain momentum.
*   **Improving Narrative Cohesion:** The AI's grounding in the project's context ensures that its suggestions and drafts are consistent with the established narrative, reducing the likelihood of plot holes or continuity errors.
*   **Preserving Authorial Voice:** The user remains in complete control. Every change is a suggestion, presented clearly for approval. The `style_guide.md` helps align the AI's output with the author's unique voice, ensuring the final product is theirs.

## 3. Target User

The primary user is a writer working on a complex, multi-document project within a text-based, version-controlled environment. This includes:

*   Novelists
*   Screenwriters
*   Technical writers managing large documentation sets
*   Game writers developing narrative content

The user is comfortable with the command line and sees value in integrating their writing workflow with tools like `git`.
